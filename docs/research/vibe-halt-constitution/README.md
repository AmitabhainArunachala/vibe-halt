## Status semantics

The corpus deliberately distinguishes three kinds of statement:

- **law:** already accepted on the repository base;
- **locked map premise:** approved as the destination or boundary of this
  planning run, but not merged constitutional law; and
- **research recommendation:** evidence-backed input awaiting the linked human
  ratification gate.

Issue state, model agreement, signatures, commits, and this index are delivery
or attribution records. None is truth or ratification by itself.
